AssetPilot Storage

AssetPilot is an owner-operated real estate dashboard. Its Google Drive connection is being configured to organize, retain and retrieve the owner's selected property documents, photos and source files.

The connection is designed to keep readable folders under Asset Pilot, grouped by document type and property. The desktop dashboard keeps its working database, document index, extracted text and a limited local file cache.

This website contains information about the storage connection. It does not provide public dashboard access, account registration or document uploads.

Google Drive access

The connection requests drive.file: access to specific Drive files and folders selected for the app, and files created by the app. It does not request unrestricted access to every file in the owner's Drive.

Configuration, migration and recovery checks must be completed before this connection becomes the dashboard's primary document storage.

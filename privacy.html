Privacy policy

This policy describes the Google Drive storage connection used by the owner-operated AssetPilot dashboard.

Data accessed

With the account owner's consent, the connection creates, reads and manages app-selected Drive files and folders. It processes their contents and metadata, including names, folder relationships, file identifiers, sizes and integrity hashes. It also checks the authenticated account's email address and available Drive storage to verify the configured destination.

Purpose and storage

The data is used to store and retrieve the owner's property documents and photos, preserve filing and provenance, verify file integrity, support document extraction, and maintain recoverable backups.

Original files and protected backup copies are kept in the owner's Google Drive. The desktop keeps operational records, extracted text, an index and a limited cache. Files awaiting a verified upload may remain local. OAuth credentials and tokens are stored locally with restricted file access, separately from property documents and application source code.

Sharing and use

The storage connection does not sell Google user data, use it for advertising, or train general-purpose AI or machine-learning models on it. It sends storage requests and the required file data to Google Drive. If the owner enables a separate external extraction service, the data needed for that workflow may also be processed by that service under the owner's authorization.

We follow the Google API Services User Data Policy, including its Limited Use requirements.

Control, retention and deletion

The account owner chooses the files shared with the app and may revoke its Google access through Google Account permissions. Revoking access does not automatically delete files already stored in the owner's Drive or local operational records. Removing an active file does not immediately remove protected backup copies; backup retention and recovery dependencies are handled separately.

File deletion and local eviction are separate controlled operations. Local originals are retained until the required cloud verification and recovery checks pass.

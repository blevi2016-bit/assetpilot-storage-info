Terms of use

Intended use

AssetPilot Storage is a private document-storage connection for an owner-operated real estate dashboard. These pages describe that connection and do not offer public user accounts or access to the owner's dashboard.

Authorization and control

Only the account owner or an explicitly authorized operator may configure the connection or select files for it. Use must comply with Google's applicable service terms and the privacy policy.

Records and recovery

The owner controls document selection, access and retention. The storage connection preserves source records and supports integrity and recovery checks. It does not itself approve extracted financial figures, authorize financial transactions or replace the owner's review of source documents.

Availability

Cloud file access depends on Google Drive availability, a valid account authorization, network access and the configured storage quota. The desktop may retain extracted text and cached files for limited offline use. Configuration changes and migrations require verification before local files are removed.
